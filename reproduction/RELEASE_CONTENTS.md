# Clean prospective release bundle

This folder is assembled by an explicit allowlist. It contains the scientific protocol and amendments; fixed/resolved configuration; dependency lock; implementation and tests; source/retrieval manifests; prospective cell/query memberships and mask digests; reproduction instructions; and a checksum inventory. It excludes `private/`, `data/`, checkpoint binaries, expression matrices, logs, caches and the earlier gate ZIP. It does not change the visibility of the existing private repository.

The bundle is prepared locally for the author's inspection. Preparation is not publication, registration or proof of an external timestamp. The main annotation run must remain blocked until the authorized private prospective snapshot is recorded and its exact file hashes verify. No independent external timestamp is claimed. The PBMC3k pilot and all changes made after it are disclosed in `amendments.md`.

The proposed scientific contribution is the measured paired sensitivity of a released annotation checkpoint to query-dependent zero-gene filtering. Linear algebra and the importance of centring are established; this is not a new classifier or a claim that the mechanism was previously unknown.
